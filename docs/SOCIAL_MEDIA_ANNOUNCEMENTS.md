## Reddit

### Title

FALIZ OS BUILD 03 is released — a Debian-based Wayland desktop created in Tanzania

### Post

I’m happy to share the new FALIZ OS BUILD 03 release.

FALIZ OS is an independent Debian-based desktop operating-system project created by Fahad Mohamed from Tanzania 🇹🇿. Fahad is an Advanced-level student who has spent approximately two years developing the project.

BUILD 03 includes a polished Sway Wayland desktop, native GTK4/Libadwaita FALIZ shell and Settings app, Waybar panel, floating dock, application launcher, virtual workspaces, notifications, dark/light themes, network and audio tools, and a broader desktop application suite.

The release is available as a verified Debian Bookworm amd64/x86_64 live ISO. It can be tested from a USB drive using Rufus or Ventoy without immediately modifying the internal disk.

Download the release:
https://github.com/gamesiteonline/faliz-os/releases/tag/v0.3.0

ISO:
https://github.com/gamesiteonline/faliz-os/releases/download/v0.3.0/faliz-os-build-03-live-amd64.iso

Please read the release notes and verify the SHA-256 checksum before writing the ISO to USB. The full graphical installer and permanent disk-installation workflow are still under development.

Source code:
https://github.com/gamesiteonline/faliz-os

Feedback, testing reports, and suggestions are welcome.
